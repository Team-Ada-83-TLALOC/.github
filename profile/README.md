# Ada 83 TLALOC

## An auditable software and hardware ecosystem built around Ada 83 (ANSI/MIL-STD-1815A-1983)

The TLALOC project explores the development of a comprehensive software and hardware ecosystem based on the original Ada 83 language standard (ANSI/MIL-STD-1815A).

The choice of Ada 83 is deliberate. Rather than following the successive extensions of the Ada language, the project focuses on mastering a stable, well-defined language and its entire implementation chain, from source code to physical hardware.

## Design principles

- Strict adherence to the Ada 83 language standard.
- Compiler self-hosting and technological independence.
- Readability, maintainability and auditability of software and hardware.
- A well-defined intermediate representation (LLIR).
- Exploration of both conventional and dedicated processor architectures.
- Preservation and further development of historical Ada software engineering knowledge.
- Effective human–AI collaboration in software and hardware engineering.

## Long-term objective

The objective is not merely historical preservation or implementing another Ada compiler, but to investigate how a complete, understandable and independently auditable computing environment can be built around a stable programming language.

From historical 8-bit processors to dedicated silicon implementations, TLALOC aims to explore the relationship between programming language semantics, compiler technology, operating environments and computer architecture.

The project also investigates how artificial intelligence can assist human engineers in developing and maintaining complex systems without sacrificing human understanding and technical control.
